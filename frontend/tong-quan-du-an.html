Tính năng

✅ Tính năng nghiệp vụ
Quản lý hồ sơ – Tạo, sửa, lưu trữ công việc với phân loại (CHUYỂN ĐỔI SỐ, TRIỂN KHAI, DNIS, MAIL…)
Ghi nhật ký đa loại – Điện thoại (DNIS), Email, Phối hợp, Cuộc họp
Kế hoạch tuần – Lịch dạng calendar, sắp xếp công việc vào ngày
Pomodoro Timer – Đếm giờ tập trung với thời gian tùy chỉnh
Tìm kiếm & lọc – Full-text search, lọc theo loại, trạng thái, ưu tiên
Focus Mode – Ẩn sidebar, hỗ trợ dark/light theme
🔧 Tính năng kỹ thuật
Cloud Sync – Backup/restore lên Google Drive qua OAuth2
localStorage – Lưu dữ liệu trên trình duyệt, không cần server DB
XLSX Export – Xuất dữ liệu ra file Excel qua SheetJS
File Explorer – Mở thư mục Windows từ trình duyệt qua Node.js server (port 3001)
Folder Search – Tìm thư mục đệ quy từ D:\
Import JSON – Import hồ sơ hàng loạt theo template
